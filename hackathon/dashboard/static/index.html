PROCESS LIFECYCLE & ANOMALY MECHANICS

Understanding kernel-level process state transitions and why zombie and orphan conditions occur in multi-tasking environments.

PHASE 01

Creation (fork & execve)

The parent process executes fork(), cloning its address space and creating a child with a unique PID. The child replaces its memory image via execve() and commences execution.

State: 'R' (Running) or 'S' (Sleeping)
PHASE 02

Termination (exit)

The child calls exit(code). The Linux kernel frees its virtual memory, stack, heap, and open file descriptors. However, its Process Control Block (PCB) must be retained.

Kernel retains 32-bit exit status
ANOMALY: ZOMBIE

Zombie State ('Z' / Defunct)

Until the parent process invokes wait() or waitpid(), the terminated child exists as a zombie. While consuming zero CPU and RAM, it permanently reserves a PID slot in the kernel table.

Risk: Exhausts /proc/sys/kernel/pid_max
ANOMALY: ORPHAN

Orphan Reparenting

If the parent terminates before the child, the surviving child becomes an orphan. The Linux kernel automatically reparents the child to init (PID 1) or an active ancestor subreaper.

Mechanism: prctl(PR_SET_CHILD_SUBREAPER)

Rightmost Parenthesis Delimiter Rule

In Linux /proc/[pid]/stat, the process command name is enclosed in parentheses and may contain spaces or nested parentheses (e.g., (worker (gpu) thread)). ProcessScope isolates the name by finding the first ( and the terminal ), preventing token corruption.

Snapshot Heuristic vs. Historical Truth

A single snapshot showing PPID == 1 cannot mathematically prove a process was orphaned; standard system services (e.g. cron, dbus) are spawned directly by PID 1. ProcessScope responsibly labels these as adopted_candidate rather than falsely asserting orphanhood.

Controlled Demonstration Harness

To definitively prove lifecycle transitions, ProcessScope provides two standalone C programs: zombie_demo (holds child un-reaped until input, then cleans up with waitpid()) and orphan_demo (proves child reparenting after parent exit with automatic timeout).
